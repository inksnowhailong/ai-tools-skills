# 议会协议模板

主持人在各步直接套用。占位符用 `{}`。

## 落盘目录

```
~/.tvs-council/{YYYY-MM-DD}-{议题短名}/
├── 00-议题.md          发起人原话 + 中性议题陈述
├── 01-事实清单.md
├── round-1.md          首轮四席发言原文
├── round-{n}.md        自由轮四席回信原文（含弃权）
├── 分歧登记表.md       每轮覆盖更新
└── 纪要.md             结束时写
```

议题短名取 2-6 个字，只用中文、字母、数字、连字符。目录在第 2 步发起人确认议题陈述后创建。`~` 指用户主目录，写入前展开为绝对路径。

## 第 2 步：盲审改写

```
## 中性议题陈述

意图：{发起人要达成什么，一句话}
约束：{明确说过的限制；没有写"无"}
已知事实：{发起人给出的、可当事实用的信息；去掉倾向句}
```

删除规则：凡是表达偏好、预设答案、情绪或对议会的要求的句子一律删。示例：

| 原话 | 处理 |
|---|---|
| 我打算把 A 换成 B，我基本想好了就用 B | 意图：A 的替代方案选择。已知事实：现状是 A |
| 别光附和我 | 删 |
| 我觉得 X 更好 | 删 |
| 上线时间是下月底 | 约束：下月底上线 |

改写后对发起人说：

```
中性议题陈述如上。确认后开会，或告诉我哪里改写错了。
```

## 第 3 步：事实清单

```
## 事实清单

### 本地现状
- {事实}（来源：{文件路径 / git 引用 / codegraph 符号 / 约定或系统说明的名称}）

### 外部权威
- {事实}（来源：{链接或文献}）

### 发起人提供
- {去掉倾向句后的原话}
```

无内容的分节写"无"。三节全无时整份写"事实清单为空"，仍然发给席位。

## 第 4 步：首轮投递

第一批（同一条消息里两次 Agent 调用）：

```
Agent(name="council-sixu", subagent_type="general-purpose", prompt=
  通用段 + 「思绪」专属段 +
  "\n\n## 中性议题陈述\n" + {陈述} +
  "\n\n## 事实清单\n" + {清单} +
  "\n\n请发言。")
Agent(name="council-jiagoushi", ...同上，换「架构师」专属段)
```

第二批（收齐前两席回信后，同一条消息里两次 Agent 调用）：

```
Agent(name="council-qiongchali", subagent_type="general-purpose", prompt=
  通用段 + 「穷查理」专属段 +
  "\n\n## 中性议题陈述\n" + {陈述} +
  "\n\n## 事实清单\n" + {清单} +
  "\n\n## 「思绪」发言\n" + {原文} +
  "\n\n## 「架构师」发言\n" + {原文} +
  "\n\n请发言。")
Agent(name="council-yonghu", ...同上，换「用户」专属段)
```

呈现给发起人：

```
## 第 1 轮

### 「思绪」
{原文}

### 「架构师」
{原文}

### 「穷查理」
{原文}

### 「用户」
{原文}
```

## 第 5 步：分歧登记表

```
## 分歧登记表（第 {n} 轮后）

| 议题点 | 各方立场 | 未被说服的一方 | 能定案的证据 |
|---|---|---|---|
| {争议的具体陈述} | 「思绪」：… ／「架构师」：… ／发起人：… | {席位名或发起人；首轮里尚未看到对方观点的一方填"待回应"} | {什么证据出现就能定；没有写"无"} |

"各方立场"一列只摘录席位与发起人的原话片段，不改写、不概括。
```

登记完，写 `round-{n}.md`（本轮四席原文）和 `分歧登记表.md`（覆盖），然后停下：

```
AskUserQuestion:
  question: "第 {n} 轮结束。下一步？"
  options:
    - 插话        我有话要说，说完再来一轮
    - 再来一轮    直接进自由轮
    - 拍板        我定了，出纪要
```

发起人选"插话"后，用纯文本等发起人输入，收到后进入第 6 步。发起人在任何时候说"散会"，进入第 8 步，结论写"未拍板"。

## 第 6 步：自由轮广播

纪要正文（四席收到的完全相同）：

```
## 第 {n} 轮纪要

### 「思绪」
{上一轮原文}

### 「架构师」
{上一轮原文}

### 「穷查理」
{上一轮原文}

### 「用户」
{上一轮原文}

{发起人插话原文，不加标题、不加署名，作为独立段落放在此处；没有插话则无此段}

---
以上是本轮全部发言。你可以回应任何人、改口、提新路，或只回"弃权"。
```

发送（同一条消息里四次 SendMessage）：

```
SendMessage(to="council-sixu", message={纪要正文})
SendMessage(to="council-jiagoushi", message={纪要正文})
SendMessage(to="council-qiongchali", message={纪要正文})
SendMessage(to="council-yonghu", message={纪要正文})
```

四席回信收齐后，按席位顺序原样呈现，回到第 5 步。全部弃权时呈现：

```
## 第 {n} 轮
四席均弃权。
```

然后照常登记（写"本轮无新分歧"）并停下。

## 第 8 步：纪要

```
# {议题短名}（{YYYY-MM-DD}）

## 中性议题陈述
{第 2 步的陈述}

## 结论
{拍板：发起人原话 ／ 散会：未拍板}

## 各席最终立场
- 「思绪」：{≤ 5 行}
- 「架构师」：{≤ 5 行}
- 「穷查理」：{≤ 5 行}
- 「用户」：{≤ 5 行}

## 分歧登记表
{最后一轮的表}

## 未决项与缺失证据
- {登记表里"能定案的证据"一列非"无"的条目}

## 轮次
{n} 轮，发言原文见同目录 round-*.md
```

未拍板时"结论"一节只写"未拍板"，不得出现主持人建议。
