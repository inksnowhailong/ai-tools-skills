# 跨项目契约协议

> 仅在**多项目并行、且互相依赖接口**时用。单项目用不到。

## 规矩

1. **指定契约源头**：leader 让**提供方项目**的角色把当前接口约定写进 `.tvs-boss/contracts.md`，带**版本号**（v1、v2…）。
2. **改一次 +1**：契约一变，版本号 +1，旧版作废（contracts.md 只留**当前**版本，不留变更史——记忆有界）。
3. **广播给依赖方**：leader 通过 SendMessage 把"契约升到 vN"连续推给所有依赖方角色，依赖方按最新版对齐 / 重跑。
4. **对齐才动手**：依赖方动工前先确认手里的契约版本 = contracts.md 当前版本，不一致先同步，避免拿过期契约白干。

## contracts.md 格式

```markdown
## shirehub ↔ way-community（v3）
- 接口约定：……（当前有效的那版）
- 提供方：shirehub
- 依赖方：way-community（按 v3 对齐）
```

> 只存"当前契约"，不存"契约怎么从 v1 变到 v3"——那是历史，归 git。
